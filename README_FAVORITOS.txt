FUNCIONALIDAD NUEVA: FAVORITAS

- Haz clic en el corazon de una tarjeta para marcar o desmarcar una moneda.
- En el menu lateral, debajo de About, aparece Favoritas.
- La pantalla Favoritas muestra solo las monedas que hayas marcado.
- No se instalaron dependencias adicionales.
- Por simplicidad, los favoritos se guardan en useState: se reinician cuando recargas la pagina.

IMPORTANTE: El ZIP parte de los archivos originales que compartiste, no de los cambios locales posteriores de Child.jsx / MyProvider.jsx. Si quieres conservar dichos cambios copia esos archivos de tu carpeta actual antes de reemplazar el proyecto.

Para probar: npm install y npm run dev.
Para publicar: npm run build y firebase deploy --only hosting --project coins-examen-final.
